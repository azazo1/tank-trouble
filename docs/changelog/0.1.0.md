# Tank Trouble v0.1.0

Date: 2026-09-05

本版本首次提供基于 Godot 4.7.1 的离线桌面版, 覆盖 macOS Apple Silicon, Linux x86_64 和 Windows x86_64.

## Highlights

- 在 macOS, Linux 和 Windows 提供统一的发布流程和对应归档.
- 支持 BootCamp 单人对 Laika, 双人本地对局和三人本地对局.
- 保留原版人数选择, 操作分配, 菜单, 音量和画质设置.
- 使用 annotated tag 触发三平台构建, 自动上传归档和 SHA256SUMS.

## Upgrade Notes

1. 根据系统下载对应归档: macOS 使用 DMG, Linux 使用 tar.gz, Windows 使用 zip.
2. macOS 版本面向 Apple Silicon, Linux 和 Windows 版本面向 x86_64.
3. macOS 应用未进行 Apple 公证, 首次打开时按系统提示完成确认.

## Features

- 提供离线本地游戏流程, 包括开始对局, 返回菜单和再次开始.
- 保存音量, 画质和操作分配, 并在设置文件损坏或版本未知时保持默认配置.
- 使用原生 GDExtension 运行物理, Spine 和 P2 相关逻辑.

## Bug Fixes

- 修复窗口缩放, HUD 定位, 输入重置和焦点丢失后的按键状态.
- 修复护盾跟随, 粒子坐标, 相机更新和回合流程中的状态同步.
- 修复 Debug 和 Release 原生扩展混用导致的启动和内存约定问题.
