# Tank Trouble Local

这是一个使用 Godot 4 制作的坦克动荡本地双人版本. 项目不加载原站网页和在线服务, 游戏从 `main.tscn` 直接启动.

## 运行

```shell
just run
```

也可以在 Godot 编辑器中打开项目并运行主场景.

## 操作

- 玩家 1 使用 `WASD` 移动和转向, 使用 `Space` 开火.
- 玩家 2 使用方向键移动和转向, 使用 `Enter` 开火.
- 菜单中使用 `Tab` 切换经典模式和死斗模式, `1` 和 `2` 可以直接选择.
- 游戏中按 `Esc` 返回菜单, 按 `R` 立即重开当前模式.

## 模式

- 经典模式: 每回合只有一次生命, 击毁对手后获得回合分, 先拿到 3 分的一方获胜.
- 死斗模式: 单回合 60 秒, 被击毁后会重生, 击杀数最高的一方获胜.

## 玩法

游戏包含随机补给箱, 双管, 散弹, 激光, 追踪导弹, 加特林, 护盾, 加速和地雷. 子弹会在迷宫墙面反弹, 激光沿迷宫通道延伸, 追踪导弹会在延迟后修正方向, 地雷会在部署后自动触发并释放破片. 坦克, 子弹, 爆炸, 护盾和补给均由 Godot 2D 绘制和脚本驱动.

## 资源

HAR 文件中的菜单背景和游戏贴图图集已提取到 `assets/sprites/`. 原始 HAR 保留在 `assets/` 供后续继续提取音频和装饰资源.

## 结构

- `scripts/game/game_root.gd`: 回合, 模式, 输入和战斗流程.
- `scripts/game/maze.gd`: 迷宫布局, 墙体碰撞和补给出生点.
- `scripts/entities/tank.gd`: 坦克绘制, 移动状态和武器状态.
- `scripts/entities/projectile.gd`: 子弹移动, 墙面反弹和轨迹.
- `scripts/game/world_effects.gd`: 补给, 地雷, 激光和爆炸特效.
- `scripts/game/hud.gd`: 菜单, 计分板, 倒计时和结算界面.
